# 回归验证

在 Windows 项目根目录运行：

```powershell
.\Tests\Run-RegressionTests.ps1
```

脚本构建 Release，使用系统 .NET Framework C# 编译器编译测试程序，再运行真实应用程序集。需要本项目已有的 .NET SDK、.NET Framework 4.8 构建环境及资源依赖，无需安装测试框架或连接 MEGA。

覆盖解压同名文件保护、ZIP 空目录、盘符和 UNC 根路径、无扩展名重命名、下载断点恢复、同名并发任务、旧版临时文件迁移、新临时文件身份的持久化及清理、完整成品恢复、流媒体 Range 分段和尾块。7z 测试使用仓库自带的 `Resources/Binaries/7zr.exe` 创建小型压缩包。

v2.6 新增批量预检与定时下载验证：新旧链接身份去重、队列重复、失效与网络故障区分、零字节文件、文件夹元数据复用、取消、磁盘空间查询；每日与跨午夜时段、一次性预约、配置 XML 往返、旧配置兼容、手动暂停与真实队列状态联动。预检接口使用注入的元数据夹具，调度测试使用内存中的配置对象，不访问 MEGA 或真实用户配置。

预检增强覆盖筛选范围反选、全局全选 / 全不选、Ctrl/Shift 所选行批量操作、虚拟列表共享行、十万条记录的增量选中统计与超大字节数汇总；后台预检任务复用、追加链接缓存、新旧格式别名缓存、队列动态去重、重试、清空和取消过时任务。原生窗体使用隔离夹具验证粘贴提前预检与确认窗口复用结果，验证批量导入不创建实际下载文件，并输出一万条列表绑定 / 全选和十万条模型操作的只读耗时。

工作台复查补充了文件夹父子重叠反选、折叠保留选择、筛选保护隐藏选择与部分选中状态；队列快照区分进度变化、状态成员变化和真实文件名 / 路径变化，包含“分组计数不变但成员互换”的情况；定时配置保留两种模式的已保存时间。

两步添加流程用例适配嵌入式预检页：返回 / 下一步保持搜索和未勾选项，复用同一页面及元数据请求；构建期间冻结选择并可取消，提交期间禁止取消；确认通过事件通知宿主，保留页面直到提交成功。同步检查取消按钮不携带自动关闭宿主的 DialogResult。

发布前审查补充：在文件选择页收到链接时暂存、保留原勾选，返回后合并并复用缓存；构建期间即使有排队的选择回调也不改变当前批次。

2026-10-29 的发布前检查中，Debug 和 Release 回归各通过 291 项断言；后续清理后 Release 再次通过。回归使用隔离夹具，不代替实际窗口操作与真实 MEGA 下载验证。

测试数据及日志保留在系统临时目录，控制台会输出位置；不读取真实账户或下载队列。

启动回归覆盖恢复后的单任务暂停、跨进程参数互斥，以及内置语言文件内容不变时不重写、内容变化时更新。互斥测试使用独立名称和临时文件，不接触正在运行的应用实例。

也可以验证 Debug：

```powershell
.\Tests\Run-RegressionTests.ps1 -Configuration Debug
```
