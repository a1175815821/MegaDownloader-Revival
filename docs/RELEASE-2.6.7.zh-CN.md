## 主要功能

### ☁️ 公开分享订阅

- 在添加链接的预检里选中公开分享中的目录，点「订阅此目录…」；当前这一批仍可照常下载。
- 订阅单独决定是补齐已有文件，还是只跟踪今后的新增与更新；保存前显示匹配数量、已在队列与已下载数量，以及本次实际加入多少。
- 之后的改动按版本识别，保留云端子目录结构；空目录也能先订阅。
- 「订阅」窗口的来源列表新增「公开分享」，公开订阅与各账号的云盘订阅一起管理：逐个文件的变化与状态、立即检查、修改设置、打开实际下载位置、取消订阅（不会删除已入队任务或本地文件）。

### 👤 下载身份

- 每个公开订阅可固定为匿名或某个 MEGA 账号；更改身份只影响之后入队的文件。
- 目录检查始终走公开链接，账号退出登录不会漏掉更新；等待指定账号的任务显示「等待 MEGA 账号登录」，配额等待也不换号。
- 公开文件夹中的子文件现在可由选定账号传输，不再只支持独立的公开文件链接。

### ⚡ 下载与完成校验性能

- 下载热路径使用缓冲池和系统 AES 批量 CTR 解密，减少大对象分配和逐块调用；微基准解密吞吐约 139 → 553 MB/s。
- MetaMAC 完成校验改为整 chunk 系统 AES-CBC（吃 AES-NI），大文件按「顺序读 + 并行算」分组处理；16MiB 校验 131 → 32ms，512MiB 3.64s → 0.20s（冷）/0.15s（热）。
- 队列 430ms 后台 tick 减负：按短快照渲染、单帧 UI 更新、移除强制 GC/清工作集；大队列下界面更跟手。

### 🗂️ 队列与存储

- 订阅清单与公开下载历史使用 Windows DPAPI 保存，队列中的分享链接按加密字段持久化。
- 清单读取不完整时拒绝写入基线，避免把未读出的文件误判为新增。
- 订阅设置新增「订阅」页：可暂停所有订阅的定时检查，并为新订阅指定默认检查时间与入队方式；恢复检查后补查一次。
