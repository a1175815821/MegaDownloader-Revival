# WinForms 视觉整理实施记录

> 后续缺陷修复与真实加载耗时复查见 [UI 第二轮缺陷复查](UI-BUG-REVIEW-20261031.zh-CN.md)。

日期：2026-10-31。采用“侧栏工作台”方向，已落实到原生 WinForms 代码。

## 已完成

- 主窗口采用中性分层配色、统一中文字体策略、24px 内容边距、40px 列表行高和统一的线形导航图标。
- 添加链接保留主操作强调，开始、暂停、停止、定时等命令改为轻量外观；公共按钮保留原生点击、键盘、焦点和 DialogResult 行为。
- 标题、任务计数、工具栏和搜索框集中在任务区，侧栏底部显示速度及队列进度。
- 空队列使用独立引导；筛选无结果使用不同文案。详情在选中任务后按需显示，宽窗口放在右侧，较窄窗口放在底部。
- 默认六列为名称、大小、状态、进度、速度、预计时间。百分比与细进度条合并；状态颜色只用于状态及进度，不再给完成／失败任务整行染色。
- 名称成为 TreeListView 的第一列，保留包／文件树展开；隐藏的优先级列继续提供队列排序，仍可从列菜单显示。
- 添加链接和预检统一字体、间距、按钮外观与确认操作位置；设置改为可缩放、可滚动的表单，连接选项独立分组，标签栏去掉系统立体边框。
- 支持的 Windows 版本使用系统原生的标题栏颜色接口，旧系统保留原有窗口边框。深色样式分别校准主按钮、辅助文字、选中和禁用状态。
- 修正 DPI 配置段写法，使用单一的 DPI 几何缩放基准，并保留字体点大小与窗口工作区约束。

首次使用新版会迁移到新的六列布局，因为 TreeListView 的首列职责发生了变化；后续保留列菜单里的用户调整。其余列仍可通过列菜单恢复。

## 一并修正的问题

- 旧 Resize 处理会将隐藏窗口强制显示，可能在构造／布局过程中触发真实加载与重复初始化。启动和托盘恢复继续通过显式入口显示窗口，Resize 不再负责显示。
- 自定义进度 renderer 没有先清除单元格背景，原生文字可能透到进度条下面。现在先绘制正确背景，再绘制进度和百分比。
- 恢复默认列后刷新虚拟列表缓存及原生主题，避免旧单元格表现残留。
- 原测试会因 Resize 的隐式显示而失去隔离，不能据旧截图认定主题正确。最终截图使用禁止业务 Load / Shown 的原生界面夹具，保留真实控件树，并校验构造与缩放不会启动实际应用。

## 验证

本轮实施时 Debug / Release 编译成功；当时 Release 完整回归通过 **354 项断言**，其中界面专项通过 116 项。十个语言包及配置 XML、新增语言键和差异空白检查通过。界面用例覆盖：

- 深浅色、空队列、示例任务、状态文字、合并进度、默认列与隐藏优先级排序。
- 文件树展开／折叠、详情在 1400 / 900 / 700px 窗口宽度下不覆盖列表。
- 添加链接、预检、设置、定时窗口的原生绘制；原有预检、取消、调度与下载恢复回归。
- 十个语言包 XML、新增语言键、项目及应用配置 XML、Git 差异空白检查。

截图使用示例任务。真实 MEGA 下载、多显示器切换及不同设备上的 125% / 150% / 200% DPI 仍需实机体验；不能把隔离截图视为这些场景已验收。
