# 公开分享文件夹订阅 · 2.6.7 交互方案

> 本方案已在 2.6.7 实现。设置 → 订阅 还可暂停所有订阅的定时检查，并为新订阅指定默认检查时间与入队方式；首版默认值仍为每天 09:00、自动加入队列。

用户拿到公开 MEGA 文件夹链接后，可以订阅整个分享或其中一个子目录。比如「公开课程 / 讲义」已有 80 份 PDF，用户只想收以后的讲义。创建时队列增加 0 项。下周发布第 81 份时，它会按订阅设置出现在下载队列或待确认列表里。整个流程可匿名完成。

## 从预检开始

沿用「添加链接 → 预检」。工具栏增加次要操作「订阅此目录…」。单独打开一个公开文件夹时，初始高亮链接所指的目录。用鼠标或键盘移到子目录，操作即指向该子目录。选中文件、多行或多个分享时，此操作不可用。右键一个目录也可以订阅它。目录为空或内容已全部入队时，仍可订阅。

- **行高亮**决定订阅哪个目录。弹出的设置窗口在标题下方显示完整的分享内路径，如「公开课程 / 讲义」，并注明「包含子目录」。
- **复选框**决定本次普通下载哪些文件。临时搜索、“文档”等类型筛选以及勾选结果均留在预检页。订阅条件在设置窗口单独确认。
- 直接粘贴指向子目录的链接，就从该子目录开始。混合粘贴时可逐个选择目录。两个分享各有一个「讲义」时，标题显示各自的分享名。
- 订阅使用公开链接访问。在「添加链接」已选账号、当前账号预检不能展开公开文件夹时，对该链接提供「以公开链接预览」入口。打开对应的目录预览，本次其他链接保留原有下载身份。

## 创建订阅

复用现有订阅设置窗口的本地目录、扩展名、检查时间与入队方式。以下是填写后的示例，括号表示单选状态。

```text
订阅公开目录
公开课程 / 讲义（包含子目录）

保存到        D:\课程\讲义                       [浏览…]
文件类型      pdf                               留空表示全部
下载身份      学习账号 ▾                         可选匿名或已添加的 MEGA 账号

首次订阅      (●) 只接收今后的新增和更新
              ( ) 同时下载已有文件

检查时间      每天 09:00 ▾
以后有更新    (●) 自动加入下载队列   ( ) 先让我确认

当前有 80 个匹配文件，本次加入 0 个文件。以后使用「学习账号」下载。

                                  [取消]  [创建订阅]
```

**首版默认值**为「只接收今后的新增和更新」「每天 09:00（本机时间）」「自动加入下载队列」，文件类型默认全部。检查时间也可选「仅手动」。保存位置预填为本次下载目录下的订阅目录名，用户选定的最终路径直接承接目录内容。例如云端的 `讲义/第 2 周/上课.pdf` 落在 `D:\课程\讲义\第 2 周\上课.pdf`。

**首次处理和以后处理分别生效。** 选择「只接收今后的新增和更新」，就在创建时记住当前匹配文件及版本。以后其中一份被修订，也属于更新。选择「同时下载已有文件」，表示用户已授权本次将符合条件、尚需下载的文件入队。即使以后选了「先让我确认」，本次也直接入队。比如 80 个匹配文件中有 3 个已在队列，若已选择「学习账号」，摘要显示「80 个匹配，3 个已在队列，本次使用『学习账号』加入 77 个文件」，按钮随之变为「创建并加入 77 个文件」。修改扩展名时同步重算摘要。已知已交付的同一版本沿用已有交付记录扣除。

**保存后回到原预检位置**，保留搜索词、滚动位置和勾选。刚入队的文件更新为「已在队列」。在目录行显示「已订阅」，操作变为「查看订阅」。页内反馈显示「已订阅『讲义』，下次检查为明天 09:00」，时间按实际计算。手动模式显示「已订阅『讲义』，可在订阅窗口立即检查」。取消设置直接回到预检。再次打开同一分享的同一目录，进入已有订阅，可在那里修改设置。

## 每个订阅用哪个账号下载

「下载身份」下拉框提供「匿名」和已添加的 MEGA 账号。账号沿用添加链接窗口的别名与邮箱，例如「学习账号（learn@example.com）」。新建时预填「添加链接」窗口中选定的身份，即使中途点了「以公开链接预览」，也记得原选择。没有选定账号时预填「匿名」。保存后每个订阅各自记住这个选择，重启后或修改全局默认账号后仍沿用它。

- **创建时。** 选「同时下载已有文件」时，摘要显示「本次使用『学习账号』加入 77 个文件」。选「只接收今后的新增和更新」时显示「本次加入 0 个文件。以后使用『学习账号』下载」。公开目录的定时检查始终通过分享链接进行。账号只用于文件传输。
- **入队时。** 首次补下、自动入队、手动确认都在创建任务时写入订阅当前的下载身份。把订阅从「学习账号」改为「个人账号」后，待确认的文件在点击加入队列时使用个人账号。已入队的任务继续使用各自入队时的身份，编辑窗口在身份字段下提示「更改仅对之后加入队列的文件生效」。
- **账号暂时不可用时。** 指定账号的登录已过期，公开目录仍照常检查。自动入队的任务以及用户手动确认入队的任务显示「等待登录 · 学习账号」，提供「重新登录」入口。若账号已从本机移除，订阅设置保留该账号的标识并显示「账号已移除 · 更改下载身份」。选择具体账号表示固定使用它，遇到配额等待时也由该账号恢复。队列详情显示任务实际使用或正在等待的身份。
- **回看时。** 选中公开订阅，在目录详情中能看到「下载身份　学习账号」和「更改」入口。订阅始终列在「公开分享」下。私有云盘订阅在同一位置显示所属账号，作为只读信息。

## 下次发布新文件时

在现有「订阅」窗口把顶部的「账号」选择器改为「来源」。第一项为「公开分享」，其余项沿用各账号。没有登录账号也可直接进入公开分享列表。从预检点「查看订阅」时，直接定位来源和目录。上表选中哪个目录，下表就显示它的文件。列头保留「变化」与「状态」，让用户同时看到「更新 · 待确认」或「新增 · 已下载」。

| 用户遇到的情况 | 窗口反馈与可执行的操作 |
| --- | --- |
| 自动模式发现两份新讲义 | 目录行显示「新增 2」，两份文件进入普通队列。成功交付后，订阅明细显示「已下载」，可打开本地位置。 |
| 确认模式发现两份新讲义 | 目录行显示「待确认 2」。用户勾选一份，点「加入队列（1）」，另一份留到下次。重复检查、关闭窗口、重启后仍可继续选择。 |
| 原有讲义发布了新版本 | 明细显示「更新」和对应的相对路径，按同一入队方式处理。已有本地文件按下载器的重名规则保留，打开位置指向本次实际交付的文件。 |
| 到检查时间时程序已退出 | 下次启动补查一次，然后恢复每日时间。用户随时可以点「立即检查」。单纯打开订阅窗口只展示最近结果。 |
| 分享已撤销 | 目录行显示「分享已失效」，保留上次成功检查的时间和明细。用户可立即重查或取消订阅。短时网络错误显示「检查失败 · 重试」。 |
| 用户点「取消订阅」 | 确认文案为「停止跟踪『讲义』？已加入队列的任务会继续，本地文件会保留。」按钮为「继续订阅」「取消订阅」。 |

## 交付时用这些场景验收

1. **从第 81 份开始。** 选择只接收今后更新，已有 80 份 PDF 时创建并重启。首次检查仍为 0。分享新增一份 PDF 和一张图片，订阅只收 PDF 时只入队一项，再查一次队列仍只有这一项。
2. **补齐现有资料。** 80 个匹配文件中已有 3 个在队列、2 个已有交付记录且文件仍在。选「同时下载已有文件」时摘要与实际新增任务都是 75。随后发现的第 81 份按单独设置的「先让我确认」处理。
3. **范围清楚。** 在预检搜索「第一周」并勾选两个文件，从「讲义」目录创建订阅。保存后仍能一次性下载勾选项。下周「讲义/第二周」内的文件进入订阅，同级「录像」里的文件留在订阅范围外。
4. **已有文件也能更新。** 先用 80 份讲义创建只跟踪今后的订阅。分享者修订其中一份，用户看到「更新 1」。同一版本再次检查时沿用原状态，下载完成后可以打开实际落盘的文件。
5. **空目录和重复链接。** 空的「下学期」能建订阅，上传首份文件后能收到。分别从分享根目录展开及从直达子目录链接进入同一个「讲义」，两处都定位同一条订阅。另一个分享内的同名目录可单独订阅。

6. **按入队时的身份下载。** 创建时选择「学习账号」，补下的第一份文件用该账号入队。留下另一份待确认文件，把订阅改成「个人账号」并重启。先前的任务仍显示「学习账号」，待确认文件此时入队则显示「个人账号」。再改为「匿名」，后续自动入队的任务使用匿名下载。
7. **账号过期仍能发现更新。** 在指定账号已过期、另一个账号仍在线时发布一份新讲义。订阅能发现文件，自动任务显示「等待登录」及指定账号名。重新登录后由原任务继续。用真实公开分享的子文件完成一次账号下载，核对实际使用的会话与队列身份一致。

## 与现有实现的衔接

- 预检树目前按文件的显示路径构造。订阅需要在解析公开分享时保留分享及目录的 MEGA 节点标识，用它区分同名目录、识别子目录直链，并表示空目录。创建时保存此次完整目录清单，以便下次识别新增或更新。[预检树](../Clases/PreflightTree.vb#L53) · [公开目录解析](../Clases/MegaFolderHelper.vb#L196)
- 可复用现有账号选择器的选项、别名和登录状态。当前账号下载的公开链接入口只接受独立文件链接，公开文件夹展开得到的子文件带有分享上下文。实现指定账号下载时，需要让选定的登录会话承接该子文件的实际传输，并在入队时保存订阅指定的身份。普通公开任务已有跨账号轮换，订阅明确固定账号的任务应按该账号等待和恢复。[现有身份选项](../Forms/AddLinks.Preflight.vb#L50) · [账号链接入口](../Clases/Fichero.vb#L57) · [分享子文件](../Clases/MegaFolderHelper.vb#L284) · [队列身份与轮换](../Clases/Fichero.vb#L698)
- 当前订阅窗口和定时检查以已登录账号为入口。公开分享需作为独立来源列出和检查。下载、手动确认、每日时间及队列状态继续使用现有交互。公开订阅能在零账号环境下创建、检查并完成交付，是首版验收条件。[订阅窗口](../Forms/MegaDriveSubscriptionsForm.vb#L191) · [现有定时入口](../Forms/Main.Subscriptions.vb#L45)
