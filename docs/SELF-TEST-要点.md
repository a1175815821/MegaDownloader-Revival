## 1. 失败横幅 ×（4 修复之 1）
- 造 1 个失败任务 → 底部红条出现“%N% item(s) failed”。
- 点 **×** → 横幅应**保持隐藏**（不再半秒后弹回）；列表仍红显。
- 再造第 2 个失败（计数 1→2）→ 横幅应**重新出现**（计数变了才提醒）。
- 点「Retry now」→ 非永久失败回 EnCola；配额失败保留断点续传。失败数归零 → 横幅自动隐藏。

## 2. 代理 host:port（4 修复之 2）
设置 → 代理：
- 地址填 `127.0.0.1:8000`、`[::1]:8000`、`http://proxy.local:1234/` → 保存应**不再弹 Invalid proxy configuration**；实际走的是「地址 + 独立端口框」端口。
- 地址填 `http://localhost/folder`、`http://example:secret@localhost`、`:8000`、`[::1` → 仍应拒绝保存。

## 3. 退出提示（4 修复之 3）
- 下载完成自动解压、任务在队列里**还没开始**就关主窗 → 应弹 “Files extracting, corruption danger” 并询问是否退出。
- 仅「等待分卷」（无当前解压、无待处理队列）时关窗 → **不应**弹该警告（回归测试已覆盖 `!Ocupado()`）。

## 4. 取消空错误 NRE（4 修复之 4）
- 连续分块失败 >30 次后停止 → 错误详情应显示 `(no error detail recorded)`（或真实异常），状态进 Erroneo，横幅计数 +1；**不卡死、不弹异常**。

## 5. 失败横幅重试/永久过滤（fe6a121）

## 6. 更新检查可配置（fe6a121）

- 运行时勾「检查更新」但间隔填 0/负数/非数字 → 弹错误并**不保存**。
