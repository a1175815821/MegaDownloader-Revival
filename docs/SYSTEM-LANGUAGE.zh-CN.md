# 跟随系统语言

2026-10-31

设置的一般页中，语言下拉框新增“跟随系统”。新配置以及没有有效语言选项的旧配置默认使用此模式；已有的有效手动语言选择继续保留。更改语言选项后，按原有流程保存并重启程序。

每次启动时，自动模式读取当前 Windows 用户的显示语言（`CurrentUICulture`），与数字、日期的地区格式设置分开。先匹配已安装语言包的完整语言代码，再匹配同语言、同文字体系的地区版本；找不到匹配时使用英文 `en-US`。

| 系统显示语言示例 | 应用语言 |
| --- | --- |
| 简体中文、中国／新加坡 | 简体中文 `zh-CN` |
| 繁体中文、台湾／香港／澳门 | 繁体中文 `zh-TW` |
| 英语、英国 | 英文 `en-US` |
| 法语、加拿大 | 法文 `fr-FR` |
| 日语、韩语等未内置语言 | 英文；安装有效的对应自定义语言包后优先使用该语言包 |

自动模式在配置 XML 的 `Language` 节点中保存为 `auto`，不会保存成当前检测到的具体语言，因此以后更换系统显示语言仍能在下一次启动时重新识别。此功能不在程序运行期间即时切换界面。

已有用户翻译文件不会被覆盖。自定义翻译缺少条目时，先使用同语言的内置翻译，再回退到英文；损坏的自定义文件不会阻止使用可用的内置语言。内置语言选择与英文回退不再依赖资源枚举顺序或上一次初始化状态。

验证：2.6.1 的 Release 完整回归通过 **509 项断言**。语言用例覆盖自动／手动选择、地区与文字体系匹配、缺失语言回退、重新初始化、自定义翻译保留、损坏文件回退及设置页的自动选项绑定。语言初始化用临时目录测试，不写入用户语言文件。

此功能随 2.6.1 发布；下载入口见 [GitHub Release](https://github.com/a1175815821/MegaDownloader-Revival/releases/tag/v2.6.1)。开发构建入口为 `bin/Release/MegaDownloader.exe`。
